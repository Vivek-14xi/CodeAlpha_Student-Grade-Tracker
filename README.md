# CodeAlpha_Student-Grade-Tracker
Student Grade Tracker

A simple Java console-based application to manage student records and track grades.
This project allows users to add student data, view all students, and generate performance reports with average, highest, and lowest marks.


---

Features

Add new student records

Prevent duplicate roll numbers

View all students

Generate student performance reports

Calculate:
